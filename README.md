# My Portfolio

A personal portfolio website for **Zoya Iqbal**, an Information
Technology student. The website introduces the student, presents her
education and learning interests, highlights practice projects, and
provides contact information.

## Features

-   **Home:** Introduction and links to the About and Projects sections.
-   **About Me:** Short profile, current studies, and areas of interest.
-   **Education:** Current Bachelor's studies in Information Technology
    at The Women's University and previous qualification details.
-   **Skills & Interests:** HTML, CSS, programming, DBMS,
    problem-solving, and communication.
-   **Projects:** Showcase cards for a Personal Portfolio Website and a
    Student Registration Form.
-   **Learning Journey:** A short statement about continued learning and
    improvement.
-   **Contact:** Contact message and an email link.
-   **Navigation:** Header links to the main sections and a footer link
    to return to the top.

## Technologies Used

-   **HTML5** for the page structure and content.
-   **CSS3** (via the external `style.css` file) for layout and visual
    styling.
-   **Google Fonts:** DM Sans and Playfair Display.

> The supplied HTML links to `style.css`, but that stylesheet was not
> included with the supplied file. The visual design depends on that
> file.

## Project Files

Keep these files in the same project folder:

``` text
My-Portfolio/
├── index.html
├── style.css
└── README.md
```

## How to Run

1.  Download or copy the project files into one folder.
2.  Make sure `style.css` is in the same folder as `index.html`.
3.  Open `index.html` in a web browser.

You can also open the folder in Visual Studio Code and use the Live
Server extension if it is installed.

## Customization

-   Edit the text in `index.html` to update the introduction, education,
    skills, and project descriptions.
-   Replace the sample project cards and add screenshots of your own
    completed work.
-   Update the displayed email address and the `mailto:` link in the
    Contact section. The current HTML uses `zoya123@gmail.com` as the
    displayed address but `yourname@example.com` as the link target;
    make these match your preferred contact address.
-   Edit `style.css` to change colors, typography, spacing, layout, and
    responsive styling.
-   Update the page title and meta description in the `<head>` section
    if you rename or repurpose the website.

## Notes

-   The supplied `index.html` contains the portfolio content and section
    navigation.
-   The HTML includes a navigation toggle button, but no JavaScript file
    or inline script is present in the supplied HTML. If the mobile menu
    is intended to open and close interactively, that behavior will need
    to be implemented.
-   The project section itself notes that the sample projects should be
    replaced with actual work and screenshots.
